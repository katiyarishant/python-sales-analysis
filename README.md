# 📊 Sales Analysis Project

This project performs a comprehensive sales data analysis using Python and pandas. It merges, cleans, and analyzes real-world sales data from various months in 2019 to uncover insights like the best month for sales, the most popular products, and the cities with the highest purchases.

## 🔧 Technologies Used
- Python 🐍
- pandas 📈
- matplotlib 📊
- Jupyter Notebook

## 📌 Key Steps Performed
- **Importing Libraries:** Used `pandas`, `os`, and `matplotlib` for data processing and visualization.
  
- **Merging Data:** Combined 12 months of sales CSV files into one single dataset.
  
- **Data Cleaning:** Removed `NaN` values and invalid rows, converted columns to appropriate data types.
  
- **Feature Engineering:** Extracted `Month`, created a new `Sales` column, and parsed `City` from the address column.
  
- **Analysis Performed:**
  - 📅 Best month for sales  
  - 🏙️ City with the highest sales  
  - 🛍️ Most sold products  
  - 📦 Product combinations often bought together
    
- **Data Visualization:** Created bar charts and graphs using `matplotlib` to support findings.
